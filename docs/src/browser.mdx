---
title: Browser Runtime
description: Load languages lazily and render highlighted output in client-side applications.
---

The browser package is designed for interactive clients that cannot know every language up front.

```sh
npm i @treelight/browser @treelight/typescript @treelight/theme-github-dark
```

```ts
import { createBrowserTreelight } from '@treelight/browser';
import githubDark from '@treelight/theme-github-dark';

const treelight = createBrowserTreelight({
  themes: [githubDark],
  theme: 'github-dark',
});

treelight.registerLanguage(
  'typescript',
  () => import('@treelight/typescript'),
);

const html = await treelight.highlight('const ok: boolean = true;', 'typescript');
```

## Lazy Language Loading

Register each language with a dynamic import:

```ts
treelight.registerLanguage(
  'javascript',
  () => import('@treelight/javascript'),
);
treelight.registerLanguage('rust', () => import('@treelight/rust'));
treelight.registerLanguage('zig', () => import('@treelight/zig'));
```

This keeps each grammar out of the JavaScript chunks. Language packages automatically select their browser entry in Vite and Astro, which emit the grammar as a hashed `.wasm` asset. The first highlight fetches it and later highlights reuse the registered parser. No application-specific `locateFile` or asset-copy configuration is required.

Node and SSR imports automatically use the self-contained embedded grammar. Explicit `/browser` and `/embedded` exports are available when an application needs to override the automatic selection.

## Themes

Themes are regular Treelight theme definitions. You can register them during initialization or load them when the user changes theme:

```ts
const theme = await import('@treelight/theme-tokyonight');
treelight.registerTheme(theme.default);
```
