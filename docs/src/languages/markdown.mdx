# Markdown

Use `@treelight/markdown` to register Markdown syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/markdown` |
| Language ID | `markdown` |

## Install

```sh
npm i @treelight/core @treelight/markdown @treelight/markdown-inline \
  @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import markdown from '@treelight/markdown';
import markdownInline from '@treelight/markdown-inline';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [markdown, markdownInline],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'markdown');
```

## Supporting packages

| Package | Language ID | Purpose |
| --- | --- | --- |
| `@treelight/markdown-inline` | `markdown.inline` | Highlights links, emphasis, code spans, images, escapes, and table-cell content. |
