# C

Use `@treelight/c` to register C syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/c` |
| Language ID | `c` |

## Install

```sh
npm i @treelight/core @treelight/c @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import c from '@treelight/c';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [c],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'c');
```
