# POD

Use `@treelight/pod` to register POD syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/pod` |
| Language ID | `pod` |

## Install

```sh
npm i @treelight/core @treelight/pod @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import pod from '@treelight/pod';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [pod],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'pod');
```
