# Perl

Use `@treelight/perl` to register Perl syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/perl` |
| Language ID | `perl` |

## Install

```sh
npm i @treelight/core @treelight/perl @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import perl from '@treelight/perl';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [perl],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'perl');
```
