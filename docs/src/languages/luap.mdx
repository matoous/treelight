# Lua patterns

Use `@treelight/luap` to register Lua patterns syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/luap` |
| Language ID | `luap` |

## Install

```sh
npm i @treelight/core @treelight/luap @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import luap from '@treelight/luap';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [luap],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'luap');
```
