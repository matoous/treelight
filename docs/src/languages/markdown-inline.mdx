# Markdown inline

`@treelight/markdown` injects `@treelight/markdown-inline` into inline nodes and table cells. Register both packages to highlight links, emphasis, code spans, images, and escapes.

| Field | Value |
| --- | --- |
| Package | `@treelight/markdown-inline` |
| Language ID | `markdown.inline` |

```sh
npm i @treelight/core @treelight/markdown @treelight/markdown-inline
```
