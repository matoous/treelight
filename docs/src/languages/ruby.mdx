# Ruby

Use `@treelight/ruby` to register Ruby syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/ruby` |
| Language ID | `ruby` |

## Install

```sh
npm i @treelight/core @treelight/ruby @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import ruby from '@treelight/ruby';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [ruby],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'ruby');
```
