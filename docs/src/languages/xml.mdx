# XML

Use `@treelight/xml` to register XML syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/xml` |
| Language ID | `xml` |

## Install

```sh
npm i @treelight/core @treelight/xml @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import xml from '@treelight/xml';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [xml],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'xml');
```
