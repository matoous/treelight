# Kotlin

Use `@treelight/kotlin` to register Kotlin syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/kotlin` |
| Language ID | `kotlin` |

## Install

```sh
npm i @treelight/core @treelight/kotlin @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import kotlin from '@treelight/kotlin';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [kotlin],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'kotlin');
```
