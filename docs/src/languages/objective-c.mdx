# Objective-C

Use `@treelight/objective-c` to register Objective-C syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/objective-c` |
| Language ID | `objective-c` |

## Install

```sh
npm i @treelight/core @treelight/objective-c @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import objectiveC from '@treelight/objective-c';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [objectiveC],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'objective-c');
```
