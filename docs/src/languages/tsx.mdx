# TSX

Use `@treelight/tsx` to register TSX syntax highlighting with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/tsx` |
| Language ID | `tsx` |

## Install

```sh
npm i @treelight/core @treelight/tsx @treelight/theme-github-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import tsx from '@treelight/tsx';
import githubDark from '@treelight/theme-github-dark';

const highlighter = await Highlighter.create({
  languages: [tsx],
  themes: [githubDark],
  theme: 'github-dark',
});

const html = highlighter.highlight(code, 'tsx');
```
