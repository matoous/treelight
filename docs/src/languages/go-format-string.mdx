# Go format strings

Register `@treelight/go-format-string` with `@treelight/go` to highlight flags, widths, precisions, argument indexes, and verbs inside supported `fmt` and `log` calls.

| Field | Value |
| --- | --- |
| Package | `@treelight/go-format-string` |
| Language ID | `go-format-string` |

```sh
npm i @treelight/core @treelight/go @treelight/go-format-string
```

<LanguageShowcase language="go">

```go
fmt.Printf("worker %03d: %[2]*.[1]*[3]f", id, width, value)
```

</LanguageShowcase>

See [Injections](/injections) for registration examples.
