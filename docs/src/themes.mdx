---

Themes map Tree-sitter highlight captures to CSS classes and colors. Register at least one theme when creating a highlighter:

Treelight uses Helix-derived scope names but a smaller theme object format. See the [Theme Reference](/theme-reference) for all supported fields, syntax scopes, fallbacks, and Helix compatibility limits.

```ts
import githubLight from '@treelight/theme-github-light';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [githubLight],
  theme: 'github-light',
});
```
