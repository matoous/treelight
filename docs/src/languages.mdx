Install language packages by package name and pass the exported definition to the highlighter.

```sh
npm i @treelight/core @treelight/rust @treelight/theme-github-dark
```

```ts
import rust from '@treelight/rust';
```

The internal `@treelight/ecma` package provides shared ECMAScript query data for JavaScript-family languages and is not usually installed directly by applications.

AWK, comment annotations, ERB, Go format strings, HEEx, jq, JSDoc, LaTeX,
Lua format strings, Lua patterns, Markdown inline, PHPDoc, POD, and regular
expressions are commonly registered as [injection languages](/injections).
