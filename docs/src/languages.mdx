title: Languages

Install language packages by package name and pass the exported definition to the highlighter.

```sh
npm i @treelight/core @treelight/rust @treelight/theme-github-dark
```

```ts
import rust from '@treelight/rust';
```

The internal `@treelight/ecma` package provides shared ECMAScript query data for JavaScript-family languages and is not usually installed directly by applications.

Single-host supporting packages are documented with their host language: Go
format strings under [Go](/languages/go), Lua format strings and patterns under
[Lua](/languages/lua), Markdown inline under [Markdown](/languages/markdown),
PHPDoc under [PHP](/languages/php), and POD under [Perl](/languages/perl).

Cross-language and standalone injection targets remain listed in
[Injections](/injections).
