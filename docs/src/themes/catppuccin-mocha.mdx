# Catppuccin Mocha

Use `@treelight/theme-catppuccin-mocha` to register the Catppuccin Mocha color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-catppuccin-mocha` |
| Theme ID | `catppuccin-mocha` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-catppuccin-mocha
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import catppuccinMocha from '@treelight/theme-catppuccin-mocha';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [catppuccinMocha],
  theme: 'catppuccin-mocha',
});
```
