# Nord

Use `@treelight/theme-nord` to register the Nord color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-nord` |
| Theme ID | `nord` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-nord
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import nord from '@treelight/theme-nord';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [nord],
  theme: 'nord',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-nord`:

type ThemePreview = {
