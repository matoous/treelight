# Solarized Light

Use `@treelight/theme-solarized-light` to register the Solarized Light color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-solarized-light` |
| Theme ID | `solarized-light` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-solarized-light
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import solarizedLight from '@treelight/theme-solarized-light';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [solarizedLight],
  theme: 'solarized-light',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-solarized-light`:

type ThemePreview = {

const preview: ThemePreview = {
