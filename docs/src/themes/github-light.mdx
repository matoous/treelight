# GitHub Light

Use `@treelight/theme-github-light` to register the GitHub Light color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-github-light` |
| Theme ID | `github-light` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-github-light
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import githubLight from '@treelight/theme-github-light';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [githubLight],
  theme: 'github-light',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-github-light`:

```ts theme=github-light
type ThemePreview = {
  name: string;
  tokens: string[];
};

const preview: ThemePreview = {
  name: 'Treelight',
  tokens: ['keyword', 'string', 'function', 'type'],
};

console.info(preview);
```
