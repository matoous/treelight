# Everforest Dark

Use `@treelight/theme-everforest-dark` to register the Everforest Dark color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-everforest-dark` |
| Theme ID | `everforest-dark` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-everforest-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import everforestDark from '@treelight/theme-everforest-dark';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [everforestDark],
  theme: 'everforest-dark',
});
```
