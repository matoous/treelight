# Tokyo Night

Use `@treelight/theme-tokyonight` to register the Tokyo Night color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-tokyonight` |
| Theme ID | `tokyonight` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-tokyonight
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import tokyonight from '@treelight/theme-tokyonight';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [tokyonight],
  theme: 'tokyonight',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-tokyonight`:

```ts theme=tokyonight
type ThemePreview = {
  name: string;
  tokens: string[];
};

const preview: ThemePreview = {
  name: 'Treelight',
  tokens: ['keyword', 'string', 'function', 'type'],
};

console.info(preview);
```
