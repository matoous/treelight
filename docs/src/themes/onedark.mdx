# One Dark

Use `@treelight/theme-onedark` to register the One Dark color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-onedark` |
| Theme ID | `onedark` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-onedark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import onedark from '@treelight/theme-onedark';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [onedark],
  theme: 'onedark',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-onedark`:

```ts theme=onedark
type ThemePreview = {
  name: string;
  tokens: string[];
};

const preview: ThemePreview = {
  name: 'Treelight',
  tokens: ['keyword', 'string', 'function', 'type'],
};

console.info(preview);
```
