# Gruvbox

Use `@treelight/theme-gruvbox` to register the Gruvbox color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-gruvbox` |
| Theme ID | `gruvbox` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-gruvbox
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import gruvbox from '@treelight/theme-gruvbox';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [gruvbox],
  theme: 'gruvbox',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-gruvbox`:

```ts theme=gruvbox
type ThemePreview = {
  name: string;
  tokens: string[];
};

const preview: ThemePreview = {
  name: 'Treelight',
  tokens: ['keyword', 'string', 'function', 'type'],
};

console.info(preview);
```
