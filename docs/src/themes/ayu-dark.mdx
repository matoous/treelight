# Ayu Dark

Use `@treelight/theme-ayu-dark` to register the Ayu Dark color theme with Treelight.

## Package

| Field | Value |
| --- | --- |
| Package | `@treelight/theme-ayu-dark` |
| Theme ID | `ayu-dark` |

## Install

```sh
npm i @treelight/core @treelight/javascript @treelight/theme-ayu-dark
```

## Register

```ts
import { Highlighter } from '@treelight/core';
import javascript from '@treelight/javascript';
import ayuDark from '@treelight/theme-ayu-dark';

const highlighter = await Highlighter.create({
  languages: [javascript],
  themes: [ayuDark],
  theme: 'ayu-dark',
});
```

## Example

This example is rendered by this docs site with `@treelight/theme-ayu-dark`:

```ts theme=ayu-dark
type ThemePreview = {

};

const preview: ThemePreview = {

```
